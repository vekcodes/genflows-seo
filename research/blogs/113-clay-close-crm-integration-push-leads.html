TL;DR

  • Clay has a native Close integration with six actions: Lookup Objects, Create Leads, Update Leads, Create Contact, Update Contact and Subscribe to Sequence.
  • Auth is a Close API key pasted into Clay under Settings > Connections. No OAuth step.
  • Close does not stop duplicates for you in this flow. Run Lookup Objects first and create a lead only when nothing comes back. That is our recommended pattern, not a documented Close feature.
  • No native opportunity action. To create opportunities from Clay you call Close’s API through Clay’s HTTP API column.
  • Close is lead-centric. A lead is the company; contacts, opportunities and activities hang off it. Map Clay’s company row to a lead and its people to contacts.
  • Subscribe to Sequence closes the loop: enrich in Clay, land in Close, enrol straight into a Close sequence.

Clay is where outbound data gets built. Close is where a lot of lean outbound teams run the calls, emails and follow-up. The handoff between the two is where lists quietly break: duplicate leads, contacts with no company, and sequences that fire at records that were already being worked.

We already cover the same handoff for Clay to HubSpot, Clay to Smartlead and Clay to HeyReach. This is the Close version, built for teams that live in Close’s lead-and-sequence model.

The Short Answer

Use the native Clay actions for the standard path: look up the lead, create it if missing, add the contact, optionally enrol the contact in a Close sequence. Reach for the HTTP API column only when you need something the native actions do not list, mainly opportunities and custom fields.

Step-by-Step Setup

1. Create the connection

In Close, generate an API key. In Clay, go to Settings > Connections, click Add Connection, choose Close, paste the key and name the account. Use a dedicated key (for example “clay-outbound”) so you can revoke it without touching anyone’s personal access. Close lists API access on every plan, per its pricing page; see our Close CRM pricing breakdown for what else each tier gates.

2. Finish enrichment before you push

Do not write half-built rows into your CRM. Run your waterfall enrichment, verify the email, and add a formula column such as “ready to push” that is true only when company name, domain and a verified email exist. Clay actions auto-run on new rows by default, so a gating formula is what keeps junk out of Close.

3. Look up before you create

Add Lookup Objects as the first Close step and search for the lead (by company URL or name) or the contact (by email). Then make Create Leads conditional on the lookup returning nothing. We have not found a Close doc describing duplicate prevention on create, so treat this lookup as mandatory, not optional. Our CRM data hygiene guide covers why duplicates are the most expensive CRM error in outbound.

4. Create the lead, then the contact

Map company name, website and any status you want to set. Then Create Contact against the lead’s ID with name, title, verified email and phone. Order matters: the contact needs a lead to belong to.

5. Optional: enrol in a sequence

Subscribe to Sequence takes the Contact ID and the Sequence ID. Build the sequence in Close first (see Close workflows and sequences), copy its ID, and gate the action on “verified email + passed ICP filter”. Remember Close Workflows are on Growth and Scale per Close’s pricing page; check your own plan covers the sequence feature you need.

Warning: auto-run. Because actions run automatically on new rows, a half-finished table can create dozens of leads before you notice. Build with auto-run off, test on five rows, check them in Close, then switch it on.

When You Need the HTTP API Instead

Close’s API creates a lead with POST https://api.close.com/api/v1/lead/. Per Close’s developer docs, the body can carry the name, URL, a status_id, addresses, a nested contacts array and custom fields. A few details matter:

  • Use status_id, not the status name. Names can be renamed in Close and break your table.
  • Custom fields use the key custom.cf_xxx, where the ID belongs to that field. The older name-based forms are deprecated. For multi-value fields you must send the full list, because the value is replaced.
  • Opportunities, tasks and activities are posted separately, not nested in the lead call.

Rate limits

Close applies limits per endpoint group and returns a RateLimit header; on a 429 you wait the stated rate_reset seconds. We did not confirm the exact requests-per-second numbers, so for bulk pushes, run Clay in modest batches and watch for 429s rather than assuming headroom.

Sending Cold Email After the Push

Close sequences send from inside the CRM, which suits low-to-mid volume with phone in the mix. At scale, most teams keep a dedicated sender; our Close CRM cold email integration guide covers how that connects, and the HeyReach to Close guide covers the LinkedIn side. We have not verified a native reply-sync path from every sender back into Close, so check that before you rely on it (directional). Closing the Loop: Close Webhooks

Close can POST JSON events (with the changed fields) to a URL you subscribe, signed with HMAC headers, retrying failures for up to 72 hours. That makes it possible to send status changes back to Clay or an n8n flow. We found no Clay or Close doc describing a ready-made Close-to-Clay setup, so consider this a build-it-yourself pattern (directional).

Common Mistakes

  • Skipping Lookup Objects, then wondering why Close has three copies of the same company.
  • Pushing unverified emails, which drags sender reputation down the moment a Close sequence fires.
  • Enrolling before the sequence is tested, so the first real prospects become your QA.
  • Writing to Close with a personal API key, so a team change breaks the integration.
  • Treating a contact as a lead. In Close the lead is the company; one lead, many contacts.

Frequently Asked Questions

Does Clay have a native Close integration?

Yes. It offers six actions: Lookup Objects, Create Leads, Update Leads, Create Contact, Update Contact and Subscribe to Sequence.

How do I connect Clay to Close?

Generate an API key in Close, then in Clay open Settings > Connections, add Close, paste the key and name the account.

How do I avoid duplicate leads in Close from Clay?

Run a Lookup Objects step first and only create the lead when nothing is found. The Close docs we read do not describe built-in duplicate prevention on create, so this is a pattern you build, not a setting you switch on.

Can Clay create opportunities in Close?

Not with the native actions listed in Clay’s docs. Use Clay’s HTTP API column to call Close’s API, where opportunities are posted separately from the lead.

How do I fill Close custom fields from Clay?

Through the API, use custom.cf_xxx keys on the lead. Clay’s docs do not state whether the native actions expose custom fields, so test before you depend on it.

Do I need a specific Close plan for the integration?

Close’s pricing page lists API access on all plans. Workflows are on Growth and Scale, so check your plan if you want automation beyond the push itself.
