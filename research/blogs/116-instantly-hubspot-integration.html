TL;DR

  • Instantly has two separate HubSpot connections. “Old HubSpot” imports leads from HubSpot lists. “New HubSpot” exports SuperSearch leads and powers Automations. Connect the right one.
  • The Automations route is two-way. HubSpot events can trigger Instantly actions, and Instantly replies and status changes can create or update HubSpot records.
  • The list import is a one-time pull, not an ongoing sync. Its duplicate check is a checkbox you have to tick.
  • Instantly does not document specific HubSpot properties, owner assignment or opt-out writes. Test each in a sandbox before you trust it.
  • For custom properties and deals, use webhooks into n8n, Make or Zapier with a find-then-upsert step. Webhooks reportedly need a higher Instantly plan (directional).

Instantly sends the emails. HubSpot is where reps work deals and where you report on pipeline. The gap between them is where positive replies get lost, so the integration is worth setting up on purpose instead of by default.

The Short Answer

Use the Old HubSpot connection to pull a HubSpot list into a campaign. Use Automations (the New HubSpot connection) to push positive replies and status changes back. If you need deals, owner assignment or custom properties, build a webhook flow with a search-before-create step, because the native docs do not describe them.

Importing Leads from HubSpot

  1. In HubSpot, build a list under CRM > Lists and pick the object type.
  2. In Instantly, open the campaign’s Leads section and choose HubSpot as the source.
  3. Pick the list, then map each column to Email, a custom variable or Do Not Import.
  4. Tick Check for duplicates across all to skip leads already in another campaign or list.
  5. Optionally verify emails first. Instantly lists this at 0.25 credits per lead.
  6. Click Upload all.

This is a one-time import. The help article describes no ongoing sync, and does not say whether active and static lists behave differently. Re-import when the list changes, and verify before you send; see Clay to Instantly if your list comes from Clay instead.

Two-Way Sync with Automations

Instantly’s Automations builder (launched January 2026 per its changelog; the help article places it under the Agents tab, so check the live label) adds HubSpot triggers and actions (directional on the date and label).

A “Map Variables” step maps Email, first and last name, phone, company, website, job title and custom variables. The docs name no specific HubSpot properties and do not say whether custom HubSpot properties are supported. Treat that as untested. Instantly’s changelog describes the sync as real time (directional).

A starter automation: positive reply to HubSpot

  1. Trigger: Instantly lead interest status changes to interested.
  2. Action: HubSpot Find contact by email.
  3. Condition: if found, update; if not, create.
  4. Action: create a task for the owner and a note with the reply text.
  5. Test with the Data Out view on each step, then toggle on and watch the Live Feed.

Then let a HubSpot workflow take over for deals and routing; see reply handling with HubSpot workflows and lead routing.

The Webhook Route

Instantly’s developer docs list webhook events including reply_received, auto_reply_received, lead_interested, lead_not_interested, lead_neutral, lead_meeting_booked, email_bounced and lead_unsubscribed, plus custom labels sent as the event type. Payloads always carry the timestamp, event type, workspace and campaign, and usually the lead email; reply events add the reply text.

Point those at n8n, Make or Zapier, then search HubSpot by email, create or update the contact, store the Instantly status in a custom property, and create the deal. Use a HubSpot private app token with contact read and write scopes and confirm the endpoints in HubSpot’s developer docs (directional: not verified for this post). Instantly’s own posts say webhooks need Hypergrowth or higher, and they conflict on API access for lower plans, so check Instantly’s pricing page (directional); plans are covered in Instantly pricing.

Frequently Asked Questions

Does Instantly integrate natively with HubSpot?

Yes. It offers a one-time list import and an Automations connection that works both ways. Instantly’s changelog dates the Automations launch to January 2026 (directional).

Why does Instantly have two HubSpot connections?

The Old HubSpot connection imports leads from HubSpot lists. The New HubSpot connection exports SuperSearch leads and is used inside Automations. Connect the one that matches your job.

Can positive replies update HubSpot automatically?

Yes. Use an Instantly reply or interest-status trigger with a HubSpot find-contact step, then create or update the contact, and add a task or note.

How do I stop duplicates between Instantly and HubSpot?

On import, tick Check for duplicates across all. When writing back, run Find contact by email before any create. HubSpot-side dedupe is not documented by Instantly.

When do I need webhooks instead of the native integration?

When you need custom HubSpot properties, deals, owner logic or your own retries. Webhooks reportedly require a higher Instantly plan, so check pricing (directional).

Which Instantly events should I send to HubSpot?

Most teams start with reply_received, lead_interested, lead_not_interested, lead_meeting_booked, email_bounced and lead_unsubscribed.
